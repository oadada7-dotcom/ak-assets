# A&K Kitchen Example — Five Materials

This package contains the five approved material swatches used for the kitchen material-inspection prototype.

## Important naming note

The prototype used the generic label **Bone Lacquer**. The approved A&K library does not contain a finish with that exact name, so this package uses **Jo-12313 Soft Dunes** as the closest approved bone-toned lacquer sample.

## Included materials

### 01 — European Oak
- Category: Natural Veneer
- Finish: Natural matte
- Example application: Full-height cabinetry
- Package file: `materials/01-european-oak-veneer.png`
- Original archive file: `European Oak Veneer.PNG`

### 02 — Verde Bamboo
- Category: Natural Stone
- Finish: Honed
- Example application: Island and worktop
- Package file: `materials/02-verde-bamboo-marble.jpg`

## Website use

The `materials.json` file contains ready-to-use names, categories, finishes, applications and relative image paths for the interactive material-inspection component.

The files in `materials/` are copies of the approved source swatches and have not been recoloured.
